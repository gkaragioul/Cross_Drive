# Disclaimer

CrossDrive is an **abandoned research project**. Read this before you download,
build, install or run it.

## It can damage your data

CrossDrive reads and writes raw disks. Known behaviour, described in the
[README](README.md#known-dangerous-behaviour), can corrupt Mac-formatted drives
and make them unmountable. Other, unknown problems are likely.

- Only use it on a drive you have fully backed up, or on a disk image.
- Never use it on your only copy of anything.
- Double-check which physical disk you select.
